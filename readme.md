# Files Pattern

## Beecrowd

`[problem_number].[ext]`

- problem_number: Problem in Beecrowd
- ext: Programming Language

## Leetcode

`[problem_slug].[version].[$s].[ext]`

- problem_slug: Problem in Beecrowd
- version: Version of solution (if language change, version is added)
- $s: optional if solution was correct
- ext: Programming Language
